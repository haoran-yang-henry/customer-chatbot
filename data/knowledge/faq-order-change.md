# Bestellung oder Lieferadresse ändern

Nach Abschluss einer Bestellung können Artikel nicht mehr hinzugefügt oder entfernt werden. Bitte stornieren Sie die Bestellung in diesem Fall und bestellen Sie neu.

Die **Lieferadresse** kann nur geändert werden, solange die Bestellung den Status „Zahlung ausstehend“ oder „Bezahlt“ hat. Wenden Sie sich dafür an unseren Kundenservice. Sobald die Bestellung „In Bearbeitung“ ist, ist keine Adressänderung mehr möglich.

Nach dem Versand können Sie die Zustellung über die DHL-Sendungsverfolgung an eine Packstation oder Filiale umleiten.
