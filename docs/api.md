# API

| | |
|---|---|
| **Status** | Day 3 |
| **Base URL (local)** | `http://localhost:8000` — interactive docs at `/docs` (disabled in `prod`) |
| **Source of truth** | OpenAPI generated by FastAPI from `src/customer_agent/api/` |

## Conventions

- JSON in UTF-8; customer-facing text is German.
- Every response carries an `x-request-id` header. Clients may send their own `x-request-id`;
  it is used in all log lines of that request.
- Authentication arrives on Day 5 (JWT bearer). Until then all requests are anonymous;
  `customer_id` is never accepted from the request body.

## `GET /health`

Liveness probe. `200 {"status": "ok", "version": "0.1.0"}`.

## `POST /v1/chat`

Answers the last user message of a conversation.

**Request**

```json
{
  "messages": [
    {"role": "user", "content": "Was kostet der Versand nach Österreich?"},
    {"role": "assistant", "content": "Der Versand nach Österreich kostet 7,95 €."},
    {"role": "user", "content": "Und in die Schweiz?"}
  ]
}
```

- 1–50 messages, alternating, last message from `user`. Messages longer than 2000 characters
  are not processed (reply asks the customer to shorten).

**Response `200`**

```json
{
  "answer": "Der Versand in die Schweiz kostet 14,95 €; zusätzlich fallen Zoll und Einfuhrumsatzsteuer an.",
  "behavior": "answer",
  "sources": ["info-shipping-international"],
  "request_id": "a1f3c09e2b4d"
}
```

| `behavior` | Meaning |
|---|---|
| `answer` | Grounded answer; `sources` lists the cited knowledge documents |
| `no_answer` | The knowledge base has no answer, or a dependency failed; the answer offers a human handoff |
| `clarify` | The message could not be processed (empty, too long); the answer asks the customer |

Further behaviours (`refuse`, `escalate`, `action`) arrive with Days 4–6.

**Errors** — `422` for invalid requests (schema, last message not from the user). Provider
outages do **not** produce `5xx`; they degrade to `behavior: "no_answer"`.

## `POST /v1/chat/stream`

Same request body. Response is `text/event-stream`:

```text
event: delta
data: {"text": "Der Versand in die Schweiz "}

event: delta
data: {"text": "kostet 14,95 €"}

event: final
data: {"answer": "…", "behavior": "answer", "sources": ["info-shipping-international"], "request_id": "…"}
```

- `delta` events contain display text (citation markers already removed).
- Exactly one `final` event ends the stream. **Clients must replace the streamed text with
  `final.answer`**: an output guardrail may replace an answer after streaming started (for
  example when the model cited no source).

## Examples

```bash
curl -s localhost:8000/v1/chat -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"Kann ich auf Rechnung bezahlen?"}]}'

curl -sN localhost:8000/v1/chat/stream -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"Was kostet Expressversand?"}]}'
```
